## 📏 Spacing System

```
SECTIONS
├── Mobile:   5rem (80px) padding top/bottom
├── Tablet:   8rem (128px) padding top/bottom
└── Desktop: 10rem (160px) padding top/bottom

CONTAINERS
├── Mobile:   1.25rem (20px) horizontal padding
├── Tablet:   2rem (32px) horizontal padding
└── Desktop:  3rem (48px) horizontal padding

GRIDS
├── Mobile:   1 column, 2-3rem gaps
├── Tablet:   2-3 columns, 2rem gaps
└── Desktop:  3-4 columns, 2-5rem gaps
```

---

## 🎭 Animation Timings

```
TRANSITIONS
├── Base: 0.3s (buttons, links)
└── Smooth: 0.6s (images, complex)

SCROLL ANIMATIONS
├── Fade up: 0.6s
├── Threshold: 10% visible
└── Trigger once: true

HOVER EFFECTS
├── Button lift: translateY(-2px)
├── Image zoom: scale(1.05-1.1)
└── Border reveal: width 0 → 100%

MOBILE MENU
├── Menu fade: 0.4s
├── Link stagger: 0.05s delay
└── Total animation: ~0.5s
```

## 🔤 Typography Scale

```
HEADINGS (Libre Baskerville - Serif)
├── Hero:     clamp(2.5rem, 8vw, 5rem)      [40px - 80px]
├── H2:       clamp(2rem, 5vw, 3.5rem)      [32px - 56px]
├── H3:       1.25rem - 1.5rem              [20px - 24px]
└── H4:       0.875rem                      [14px]

BODY (Inter - Sans-serif)
├── Large:    clamp(1rem, 2vw, 1.25rem)     [16px - 20px]
├── Regular:  clamp(0.9375rem, calc, 1.0625rem) [15px - 17px]
├── Small:    0.875rem                      [14px]
└── Tiny:     0.75rem                       [12px]

LINE HEIGHTS
├── Headings: 1.1
├── Body:     1.6-1.7
└── UI:       1.4
```

## 🎯 Interactive Elements

```
BUTTONS
├── Primary (Espresso bg)
│   ├── Padding: 0.875rem 2rem
│   ├── Hover: Lift + shadow
│   └── Large: 1.125rem 2.5rem
│
└── Secondary (Transparent)
    ├── Border: 2px espresso
    ├── Hover: Fill + lift
    └── Icon: Optional

NAVIGATION
├── Desktop: Inline links
│   └── Underline on hover
│
└── Mobile: Hamburger menu
    ├── Full-screen overlay
    ├── Staggered link animation
    └── Large touch targets

MENU FILTERS
├── Chip-style buttons
├── Active state: Filled
└── Hover: Border color change

CARDS
├── Featured: Grid items
│   └── Hover: Translate + shadow
│
└── Menu Items: List items
    └── Hover: Border + translate
```

## 📊 Z-Index Layering

```
z-index: 1001  → Hamburger button
z-index: 1000  → Navigation
z-index: 999   → Mobile menu
z-index: 100   → Announcement bar
z-index: 2     → Scroll indicator
z-index: 1     → Hero content
z-index: 0     → Default (hero bg, etc.)
```

## ⚡ Performance Targets

```
LOAD TIMES
├── First Contentful Paint: < 1.5s
├── Time to Interactive:    < 3s
└── Total Page Load:        < 5s

FILE SIZES (before images)
├── HTML:       ~20KB
├── CSS:        ~25KB
├── JavaScript: ~15KB
└── Total:      ~60KB

IMAGE OPTIMIZATION
├── Use WebP where supported
├── Lazy load: loading="lazy"
├── Compress: TinyPNG or similar
└── Max size: 200KB per image
```
